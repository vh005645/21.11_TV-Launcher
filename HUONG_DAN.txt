HƯỚNG DẪN NHANH - HỆ THỐNG ĐIỀU KHIỂN TV QUA FIREBASE

1) Firebase (làm 1 lần)
   - Tạo project trên console.firebase.google.com -> Build -> Realtime Database -> Create database.
   - Copy URL dạng  https://TEN-DU-AN-default-rtdb.firebaseio.com
   - Tab Rules, dán rồi Publish:
       {
         "rules": {
           ".read": false,
           ".write": false,
           "devices": { "$id": { ".read": true, ".write": true } }
         }
       }
     (Không ai liệt kê được danh sách TV; chỉ người biết link Firebase + mã thiết bị mới truy cập được.)

2) App TV (tv_launcher): mở src/vn/herotran/launcher/RemoteConfig.java, sửa DEFAULT_DB_URL thành URL ở trên rồi build.
3) App điện thoại (tv_remote_mobile): chỉ cần dán link Firebase trong app (nút Cài đặt). Mã thiết bị đã đặt cố định sẵn trong cả 2 app.
4) Trên TV: bấm phím Menu 5 lần -> màn hình cài đặt ẩn -> bấm (1) Cấp quyền Overlay, (2) Kết nối Local ADB
   (tích "Always allow" rồi Allow trên hộp thoại), (3) Test ADB.
